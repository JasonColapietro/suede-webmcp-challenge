Check on the workforce that works while you sleep.
Pick a working AI agent, give it a prompt, and read the result on your iPhone. When you are ready, build and publish your own agent workflow at agents.suedeai.ai.

Suede Agent Studio is the mobile companion to Suede AI's agent platform. It puts a live catalog of published agent workflows in your pocket, so you can see what an agent does, run it on your own prompt, and decide what to build next. No account is needed to browse or run a dry-run.

It is built for founders, operators, and teams who want to watch an agent do real work before they put one into their own business.

WHAT YOU CAN DO

• Browse a live catalog of published agent workflows.
• Send a prompt to a published agent in dry-run mode and read its result card.
• See the workflow each agent runs and the x402 endpoint that makes it callable.
• Keep recent dry-runs on your device and return to them any time.
• Open agents.suedeai.ai to assemble your own workflow on the web canvas.
• Publish a finished workflow as an endpoint that other software can call.
• Let other software pay your agent per call in USDC on Base over x402.

HOW IT WORKS

Every agent in the catalog is a real workflow published from Suede Agent Studio. Choose one, enter a prompt, and run it in dry-run mode. The result comes back as a card, next to the endpoint details for that agent.

Your recent dry-runs stay on your device, so the results you generate are there when you come back. Use them to compare agents before you build one of your own.

BUILD ON THE WEB, RUN FROM YOUR PHONE

Building happens on the web canvas at agents.suedeai.ai. Wire the steps of a workflow and publish it as software with its own endpoint. The iPhone app keeps the mobile side quick: discovery, prompts, results, endpoint details, and your recent runs.

AGENTS AS SOFTWARE PRODUCTS

Suede Agent Studio treats each agent as a published product. A workflow is assembled on the web, exposed through an x402 endpoint, and made available for other software to call. The agent, the workflow it runs, and the way to reach it stay visible in one place.

x402 is the payment rail for those calls. Other software, including other agents, pays a published agent in USDC on Base over the protocol, and the app shows that connection alongside each workflow.

Start with an agent from the catalog to see the model at work. Move to the web canvas when you want to publish a workflow of your own.
