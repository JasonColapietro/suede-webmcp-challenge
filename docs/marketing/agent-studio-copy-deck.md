## Objection copy

### "Is this just another visual builder?"

The canvas is one layer. The same flow can sit behind a company role, move through exact Test and Live versions, export to TypeScript, and publish a public machine-callable boundary.

### "Does the agent company share one memory?"

Not as a general company-wide memory system today. Employees share company structure and governance. Subflows and loops support bounded orchestration, while broad shared memory and autonomous handoffs remain future proof points.

### "Does publishing make money automatically?"

No. Publishing makes a service available and discoverable. Payment occurs only when a compatible caller makes a valid paid call that settles.

### "Can buyers pay by card?"

Current per-call settlement uses x402-compatible USDC on Base. Stripe currently funds owner gateway credits rather than serving as buyer checkout for each agent call.

### "Why not use an incumbent automation platform?"

Choose an incumbent when native connector breadth is the first requirement. Choose Suede when the connected unit matters: role, workflow, exact Live version, public service, and receipt.

### "Is this enterprise ready?"

Suede provides concrete controls such as owner scoping, encrypted static API credentials, immutable versions, promotion gates, spend ceilings, and a public security page. It does not currently claim SOC 2, HIPAA, or ISO 27001 certification.

## Copy quality check

### Swap test

The selected hero passes because a competitor would need the connected seat, workflow, and paid-service model to use it honestly.

### Claim test

- No customer results, testimonials, revenue, ROI, or uptime were invented.
- Public call counts are explicitly separated from settled payment proof.
- Counts are timestamped or grounded in the current repository.
- Tradeoffs and non-fit cases are visible.

### Anti-slop test

- No "revolutionize," "supercharge," "seamless," "unlock," or "next level."
- No exclamation points.
- No em dashes.
- CTAs name the immediate result.

### Recommendation

Ship the category, mechanism, and proof sequence. Hold every-call revenue, shared-memory, 24/7 autonomy, buyer-card payment, broad-protocol settlement, and enterprise-readiness language until the corresponding evidence exists.
